## 🚀 How to Use

### 1. Customer Flow
* Open the application URL (or local `http://localhost:10000`).
* Browse available food items on the menu, add them to your cart, and place an order.

### 2. Admin Portal Flow
* Click the floating **Admin Portal** button on the bottom-right of the page to open the dashboard directly.
* View incoming orders and manage the system in real time.
